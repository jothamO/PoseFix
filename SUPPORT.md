# Support

PoseFix is early open-source research software, not a hosted support service.

- **Bug or reproducible engine problem:** open a bug report.
- **Feature or adapter proposal:** open a feature request.
- **Security or credential issue:** follow `SECURITY.md`; do not post secrets publicly.
- **General question:** use GitHub Discussions if enabled, otherwise open a narrowly scoped issue.

When reporting image-generation behavior, remove private metadata and use a synthetic, self-owned, or properly licensed example whenever possible.
