# Public Docs Writer

## Purpose
Turn accurate internal PoseFix material into public documentation that is easy to understand without oversimplifying the project.

## Pattern
Draft -> specialist audits -> diagnose confusion -> surgical revision -> targeted re-audit -> stop when clear.

## Required audits
Accuracy, clarity, structure, jargon, examples, compression.

## Rules
Never invent capabilities, clearly label experimental behavior, prefer concrete language, never expose private images or secrets, and do not turn documentation into marketing hype.
