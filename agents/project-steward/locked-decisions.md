# Locked decisions

1. Open-source first.
2. Skills contain domain intelligence.
3. Engine governs deterministic workflow.
4. Adapters are provider-specific translators only.
5. Core contracts remain provider-agnostic.
6. Single-person existing-photo pose correction is V1.
7. Prefer minimum necessary correction.
8. Preserve successful parts of the original pose.
9. Provider inference may be host-native or externally configured.
10. PoseFix must work without a dedicated consumer web app.
11. Build before endlessly extending architecture.
12. Natural Upgrade is an orchestration label, not a canonical preset.
13. Canonical V1 library contains ten presets.
14. Current project objective is to satisfy every Before Public Launch readiness criterion before expanding scope.
15. Live-provider validation is a required launch-readiness milestone, not the terminal project objective.
16. Do not add post-launch growth features, multi-person support, live coaching, automatic provider routing, or broad UI work until the pre-launch gate is green.
17. Launch-readiness prioritizes, in order: reliable correction quality, first-success ergonomics, embeddability, demonstrability, and distribution readiness.
18. A generated candidate that fails review must not be exposed as a successful result. Permit one targeted retry for the failed slot; if no candidate passes, fail clearly.
