# Repository release checklist

- [ ] tests pass
- [ ] lint passes
- [ ] README matches current behavior
- [ ] changelog updated
- [ ] no secrets or `.env` files
- [ ] no private or unlicensed example images
- [ ] issue/PR templates present
- [ ] security reporting instructions present
- [ ] Project Steward status is ON_TRACK or CAUTION with accepted risk
- [ ] version/tag matches release notes
